Certloom browser lab
Serve these files using localhost HTTP or HTTPS. Computation uses local BigInt arithmetic in a Web Worker; there is no CDN or computation service. file:// workers are unsupported. Examples include captured NIST FiPy linear equations and original dense mathematical systems, not hardware measurements. NIST notices and provenance accompany the FiPy data. Python checker artifacts verify the same input independently using only the standard library. Sources: https://github.com/nazeeh111/Certloom
