Method & limits

          

            Sparse certificates use positive weights and strict weighted diagonal dominance. Dense certificates use an approximate inverse and a contraction bound. Both recompute their premises and residuals with exact integers and fractions. A failed premise refuses the enclosure; an inconclusive interval leaves the threshold undecidable.
          

          

            Sparse: up to 4,096 unknowns and 32,768 nonzeros. Dense: up to 128 unknowns. Certificates up to 2 MiB. No
            uploaded code is executed. A 20-second deadline and Cancel stop only
            this computation. Serve the source bundle over HTTP; module workers
            do not run from a file:// page.
