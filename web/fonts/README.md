# Local typography

IBM Plex Sans and IBM Plex Mono are bundled as unmodified WOFF2 files from the pinned IBM/plex revision recorded in source.json. Copyright IBM Corp.; Reserved Font Name Plex. The complete SIL Open Font License 1.1 is retained in OFL.txt. IBM does not endorse this project.

The workbench loads these files locally under its existing same-origin security policy. No font service or external connection is required. System sans and monospace fallbacks remain available if a font cannot load.
